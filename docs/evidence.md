# SMART Target 1 Evidence

**Target:** Learn how to use GitHub and Git workflows to manage code versions, track changes and keep repositories organised.

## What I did

- Created a repository called `Git-and-GitHub-`.
- Made a small HTML, CSS and JavaScript task list.
- Kept JavaScript and CSS in the `src` folder.
- Put my notes and evidence in the `docs` folder.
- Made separate commits with short messages.
- Created the `feature/task-list` branch from `main`.
- Used a pull request to put the feature into `main`.

## What I learned

Git lets me keep earlier versions of my code. GitHub lets me see the changes online. A branch is good for trying something new without changing the main version. A pull request lets me check and merge the changes.

## Next step

Use this same workflow when making bigger college projects.
