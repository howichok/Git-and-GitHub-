# My Git and GitHub Notes

Git saves versions of my code. GitHub stores the repository online.

## Useful commands

- `git status` - check changed files
- `git add .` - choose files to save
- `git commit -m "message"` - save a version
- `git branch` - see branches
- `git switch -c feature/task-list` - make a new branch
- `git switch main` - go back to main
- `git push` - upload commits

## My workflow

1. Make a repository.
2. Add some files and commit them.
3. Create a branch for a feature.
4. Make changes on that branch.
5. Open a pull request.
6. Merge it into main.

A commit saves my work. A branch keeps changes separate. A pull request is where changes can be checked before merging.
