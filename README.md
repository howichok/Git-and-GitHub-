# Git and GitHub Practice

This is a small college project to practise Git and GitHub.

## What it does

It is a basic task list. You can add tasks on the page.

## Files

- `index.html` - the web page
- `src/script.js` - JavaScript for the task list
- `src/style.css` - page design
- `docs/git-guide.md` - simple Git notes
- `docs/evidence.md` - SMART Target 1 evidence

## How to run

Open `index.html` in a browser. No install needed.

## What I practised

Commits, branches, a pull request and organised folders.
